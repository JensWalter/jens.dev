title: "Tibco EMS Bindings for Rust"
date: 2020-11-18T02:13:50Z
---

The project “tibco_ems” on crates.io is a Rust library for interacting with Tibco Enterprise Message Service (EMS). It provides functionalities to connect to Tibco EMS servers, send and receive messages, and manage various messaging operations. This crate allows Rust developers to integrate Tibco EMS into their applications, leveraging the features of EMS for enterprise messaging and communication.

https://crates.io/crates/tibco_ems
