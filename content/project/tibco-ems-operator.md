The project “tibco-ems-operator” on GitHub is a Kubernetes operator for Tibco EMS (Enterprise Message Service). It enables the management and scaling of Tibco EMS instances within a Kubernetes cluster. The operator can dynamically scale deployments based on specific criteria, collect statistics, and handle various configurations for managing Tibco EMS objects. It supports features like ownership of managed objects and customization through environment properties.
